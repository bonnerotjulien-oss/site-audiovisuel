FAVICON JB — MISE À JOUR
=======================

Toutes les pages HTML utilisent maintenant directement :
assets/jb-mark.png?v=61

C'est le même monogramme JB que celui affiché dans l'en-tête du site.

À FAIRE
1. Mettre à jour/remplacer les fichiers HTML du pack sur GitHub.
2. Conserver impérativement assets/jb-mark.png dans le dépôt.
3. Attendre le redéploiement GitHub Pages.
4. Fermer complètement l'onglet du site puis le rouvrir.
5. Si l'ancien favicon reste affiché :
   - Ctrl + Shift + R
   - ou tester en navigation privée
   - Chrome peut conserver un favicon plusieurs minutes/heures en cache.

Aucun changement de design ou de SEO n'a été effectué en dehors du favicon.
